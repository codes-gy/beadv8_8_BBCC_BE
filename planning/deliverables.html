도메인별 만들 것 — API · 이벤트 ​

지금 있는 API는 API 목록에 도메인별로 있습니다. 아래 표에는 아직 만들지 않았거나 만들지 않기로 한 API와 이벤트만 남깁니다 (앞의 /api/v1 생략). 단계 열: ①~⑦ = 정상 흐름에 필요한 카드 · 보완 = 정상 흐름 다음 · 최종 = 최종 프로젝트(완료 · 진행 중 · 예정을 설명에 적음) · "만들지 않음" · "세미 제외" · "최종" 줄을 빼면 이 장의 API는 모두 구현되어 있습니다

v2.0: 이벤트는 모두 Kafka로 갑니다. 토픽은 kidly.{보내는 도메인}.events이고(3.3), 받는 쪽은 구독 그룹 kidly.{받는 도메인}으로 받습니다.
